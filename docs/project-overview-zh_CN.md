# 本地知识库问答系统

## 项目简介

这是一个面向个人知识库的本地 RAG 应用。用户上传 PDF 后，系统会完成文件校验、文本解析、分块、内容去重和索引持久化；用户可以在中文页面中基于已上传文档提问，并查看回答对应的文件、页码和原文片段。

项目采用前后端 Monorepo 结构：FastAPI 负责文档处理、检索、会话和流式接口，Streamlit 负责中文交互页面。前端只通过 HTTP 和 SSE 调用后端，不直接访问数据库或向量库。

## 已实现能力

- PDF 文件校验、PyMuPDF 文本解析和可配置分块
- SHA-256 内容去重，SQLite 元数据持久化
- Chroma 本地持久化索引和文档删除
- LangChain Retriever、Fake/OpenAI/Ollama 模型服务适配
- 对话记录、结构化引用和 SSE 流式回答
- Streamlit 中文页面：上传、列表、删除、历史恢复、引用展开
- Docker Compose 一键启动、服务健康检查、结构化日志和请求编号
- 单元测试、集成测试、容器端到端测试和 GitHub Actions
- 固定 10 篇文档、20 个问题的检索与性能评测

## 前端语言说明

业务页面、按钮、错误提示、聊天角色和引用展示均使用中文。`/docs` 是 FastAPI 自动生成的开发接口文档，部分框架字段和路径仍保留英文，这是程序接口标识，不影响前端使用。

## 如何启动

### 推荐方式：Docker Compose

准备 Docker Desktop 后，在 `D:\workspace\rag` 目录执行：

```powershell
docker compose up --build --wait
```

看到两个服务状态为 `healthy` 后，打开：

- 前端页面：http://127.0.0.1:8501
- 后端接口文档：http://127.0.0.1:8000/docs

停止服务：

```powershell
docker compose down
```

不要随意使用 `docker compose down --volumes`，因为它会删除已经上传的文档和索引数据。

### 本地 Python 方式

需要 Python 3.12、uv，并先执行：

```powershell
uv sync --all-packages --dev
```

然后分别在两个终端启动：

```powershell
uv run --package rag-api rag-api
```

```powershell
uv run --package rag-web rag-web
```

本地启动时前端仍访问 `http://127.0.0.1:8000`，页面地址仍为 `http://127.0.0.1:8501`。

## 使用流程

1. 打开前端页面，在左侧选择一个 PDF 文件上传。
2. 等待文件出现在“文档库”列表中。
3. 在页面底部输入与文档内容相关的问题并发送。
4. 观察回答逐段出现，展开“来源”查看文件名、页码和原文片段。
5. 点击“新建对话”开始新的会话；刷新页面后，当前会话记录会自动恢复。
6. 不再需要的文档可以点击“删除”，文件、数据库记录和向量索引会一并删除。

## 后续改进方向

1. **语义检索**：接入可配置的本地或云端 Embedding 模型，与当前词法基线做 A/B 评测。
2. **检索质量**：增加混合检索、重排序、查询改写，并扩充多页、表格和中文长文档测试集。
3. **回答质量**：接入真实模型服务，增加答案正确性、引用准确性和拒答率评测。
4. **数据管理**：增加会话列表切换、文档状态、批量操作和索引失败重试。
5. **性能与安全**：补充并发压测、限流、鉴权、敏感配置管理和生产级监控。
6. **部署能力**：增加 Linux 服务器部署示例、反向代理和 HTTPS 配置，但只有实际部署并记录运行数据后才写入简历。
